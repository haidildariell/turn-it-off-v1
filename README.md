Entry for the make.fun bounty [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)

A program that writes one funny single-line reply from a hopeless tech
support agent to a desperate customer to `/output/entry.txt`:

> Have you tried turning it off and on again? I ask because my entire
> training was one laminated card that just says that, in Comic Sans.

Run it with Python 3.13:

```sh
python3 main.py
```
